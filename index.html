이번 개정 핵심

Schema v1 · embedded fallback

1. 증상 기반 진입

환자가 말하는 통증 부위/증상군에서 시작해 관련 근육과 감별 포인트로 연결합니다.

2. 근육별 임상 연결

각 근육 카드에 해당 근육이 자주 등장하는 증상군을 역으로 표시합니다.

3. 퀴즈·오답복습

Origin, Insertion, Function, Nerve, Clinical 문제를 자동 생성하고 오답 근육을 기기에 저장해 반복 학습합니다.

4. 오랄 테스트

친구·동료·선배·대가 모드로 해부학·기능·촉진·MMT·임상·초음파를 말로 답하고 즉시 교정받습니다.

5. 환자교육 운동

환자가 부위 → 근육 → 쉬운 운동·스트레칭 → 주의사항 → 인쇄용 그림 매뉴얼 순서로 바로 볼 수 있습니다.

6. 전신 QA

205개 O/I/F/N, 294 임상퀴즈, 131 실제 초음파, 205 환자교육, Stable ID·PWA 무결성을 자동 검사합니다.
