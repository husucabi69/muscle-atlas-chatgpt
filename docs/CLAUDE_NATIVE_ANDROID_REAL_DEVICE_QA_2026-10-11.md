# 근육학 자체 강의 · 실제 Android 무료 한국어 음성 검수표 (2026-10-11)

상태: **REAL_DEVICE_PENDING** — 코드/Chromium 자동검사는 실제 Android에서 들린 소리·자율 시작·기기 음성 권한을 증명하지 않는다.
적용 화면: 개발 전용 안정 Preview `https://preview-development.muscle-atlas-chatgpt.pages.dev/`.
브랜치: `preview/development`; Production `main` 사용자 승인 전 승격 금지.

## 기기에서 확인해야 할 사용자 경로
1. Android Chrome으로 위 Preview를 연다. 홈 → **학술 강의실 → 근육학 → 근육학 01권 → 우리 앱 통합 강의**로 진입한다.
2. 무료 한국어 음성 → **▶ 읽기**로 시작한다. 실제 음성 청취, 현재 문단의 노란색 강조, 아래 진행 구간 숫자 증가, 화면 스크롤을 확인한다.
3. 한국어 목소리 변경, **0.75 / 1.0 / 1.5배속**, 부호 자연스럽게 건너뛰기 / 원문 그대로 읽기, 문단 터치부터 재시작을 각각 확인한다.
4. 임의의 중간 구간에서 **A 시작 → B 끝 → 반복 켜기**를 선택한다. 지정된 A~B 구간만 돌고 해제하면 다음으로 이동해야 한다.
5. **⏸ 일시정지 → ▶ 계속**, **⏹ 정지** 후 소리·강조 종료를 확인한다. 정지 후 다른 강의로 이동해도 이전 강의가 다시 재생되거나 자동으로 화면을 옮기면 FAIL이다.
6. 근육학 02~11권을 각각 열어 본문·표·그림 및 무료 읽기 버튼을 확인한다. 대표적으로 2권→3권 자동 연속듣기, 11권(카탈로그 #13)의 마지막에서 **다음 강의 자동 이동 선택이 보이지 않는지** 확인한다.
7. 1권의 **Claude 원본 여성 강사 음성**은 무료 기기 TTS와 별개이다. 원본 MP4 1부·2부를 사용자가 직접 선택한 경우에만 타임코드 강조/재생/2부 전환을 검증한다. R2 자동재생은 현재 BLOCKED.
8. 동일 경로를 Chrome과 설치 PWA에서 각각 실행한다. 화면 꺼짐·백그라운드·오프라인·TTS 음성 다운로드 여부에 따른 차이가 있으면 기기 설정과 재현 조건만 기록한다.

## 자동 다음 권 음성: 특별주의
- 한 권의 끝에서 다른 권으로 화면이 자동 이동할 수 있으나, **Android 브라우저의 사용자 제스처 제한**으로 다음 권의 음성 자동 시작이 거부될 수 있다.
- 이 경우 오류 메시지는 '브라우저가 자동 음성 시작을 제한했습니다. ▶ 읽기를 직접 눌러...'라고 안내하며, 실제 사용자가 다시 ▶를 누르면 읽기가 이어져야 한다.
- 자동재생이 잘된다는 결과는 **실제 해당 Android 기기에서** 해당 동작을 끝까지 관찰한 경우에만 PASS.
- 휴대전화 브라우저가 오디오를 자동 허용하는지, Bluetooth 이어폰 환경인지에 따라 결과가 다를 수 있다.
- 늦게 실행되는 완료 callback이 **⏹ 정지 / 앱 뒤로가기 이후 다음 강의를 임의로 열면 FAIL**. Playwright의 별도 시뮬레이션 QA는 실제 기기 검수를 대체하지 않는다.
