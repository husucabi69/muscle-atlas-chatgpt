## 의장님이 승인한 기준
- **3번 근육학 01권 어깨·견갑대** 구조를 기준으로 사용한다. 장/근육을 선택하면 바로 본문으로, 굵고 큰 글자, 분절 문단·도표·그림, 문단별 무료 한국어 TTS, 임상/해부 설명의 완전성, 이전/다음, 근거 및 경고를 유지한다.
- 학술 강의 내용을 자의로 축약하거나 임의 그림으로 대체하지 않는다. 원본 파일의 byte/SHA-256은 별도 보존하고 앱 소유 독립 레이아웃으로 읽는다.
- 모바일에서 화면을 여러 겹으로 스크롤하도록 강요하지 않는다. 적어도 강의나 근육 한 개를 선택한 뒤에는 **탭 1회 → 제목/내용 즉시 → 넓은 단일 읽기 화면**이어야 한다.
- MP4는 원본 존재·R2 재생 확인 후 연결한다. 무료 한국어 기기 음성과 원본 Claude 녹음 MP4를 혼동하지 않는다.

## 2026-10-13 v12.54 검색 복귀 root cause 수정
- 최초 표시되는 홈은 CSS에만 `active`이고 `documentElement.dataset.appPage`가 없는 상태였다. 따라서 클릭하기 전 입력한 검색어는 홈 History에 저장되지 않아 Android Back에서 빈 검색으로 복귀했다.
