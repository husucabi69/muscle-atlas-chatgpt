## 사용자 확정 방향
- 의장님은 근육학 1권의 우리 앱 전용 강의 UI와 무료 한국어 음성 읽기를 긍정적으로 검수했다. 이 품질을 유지·확장한다.
- 무료 한국어 음성은 기기/브라우저 Web Speech API(speechSynthesis) 기반이다. 유료 음성 파일을 구매하거나 새로 제작하지 않는다. 실제 음질, 기기 외부 처리 여부, 오프라인 동작은 기기와 브라우저의 엔진에 따라 다를 수 있다.
- 부호 자연스럽게 읽기/건너뛰기(원문 그대로 옵션 포함), 0.75~1.5배속, A~B 읽기 구간 반복, 선택한 장부터 듣기, 문단 터치 듣기, 각 권이 끝나면 같은 시리즈의 다음 강의를 열어 읽는 기능을 반영한다. Android의 자동 음성 시작은 브라우저 제한이 있을 수 있어 실기기 검증이 필요하다.
- 원본 학술 서술, 표, 해부 그림, 임상적 근거, 문제은행, 설명 깊이, 승인된 v11.14 근육 상세 UI는 절대 삭제·축약하지 않는다. Production main은 명시적 승격 승인 전 변경 금지.
