# Claude 학술 원본 87강: 앱 자체 이식 로드맵 (2026-10-11)

## 사용자 확정 방향
- 의장님은 근육학 1권의 우리 앱 전용 강의 UI와 무료 한국어 음성 읽기를 긍정적으로 검수했다. 이 품질을 유지·확장한다.
- 무료 한국어 음성은 기기/브라우저 Web Speech API(speechSynthesis) 기반이다. 유료 음성 파일을 구매하거나 새로 제작하지 않는다. 실제 음질, 기기 외부 처리 여부, 오프라인 동작은 기기와 브라우저의 엔진에 따라 다를 수 있다.
- 부호 자연스럽게 읽기/건너뛰기(원문 그대로 옵션 포함), 0.75~1.5배속, A~B 읽기 구간 반복, 선택한 장부터 듣기, 문단 터치 듣기, 각 권이 끝나면 같은 시리즈의 다음 강의를 열어 읽는 기능을 반영한다. Android의 자동 음성 시작은 브라우저 제한이 있을 수 있어 실기기 검증이 필요하다.
- 원본 학술 서술, 표, 해부 그림, 임상적 근거, 문제은행, 설명 깊이, 승인된 v11.14 근육 상세 UI는 절대 삭제·축약하지 않는다. Production main은 명시적 승격 승인 전 변경 금지.

## 현재 개발 배치 v12.28
- 기존 자체통합 근육학 1권(카탈로그 #3)은 19장, 표 49개, 그림 18개, 음성 표시 671개, 추가 해설 5개를 보존한다.
- 동일한 앱 통합방식으로 근육학 제2~11권(카탈로그 #4~13)을 추가한 개발 코드. 즉 근육학 11권 대상, 전체 87강 Native 통합이라고 보고하지 않는다.
- SHA-256/원본 바이트 검증 후 Shadow DOM으로 본문과 원본 디자인을 불러온다. 표/그림/섹션/문단 수 및 원문 텍스트를 비교한 뒤에만 완료로 표시한다.
- 형식 불일치, 일부 누락 또는 동적 문항 문제가 있으면 원본 비교 화면으로 되돌린다. 원본 HTML은 변경하지 않는다.
- 기능 계약: scripts/claude-native-muscle-series-qa.mjs, scripts/claude-native-muscle-audio-contract-qa.mjs, scripts/claude-original-all-lectures-e2e.mjs.
- 실제 Android 원본 MP4 재생, Cloudflare R2 원본 자동 재생, 87강 Native 완성은 아직 미완료로 취급한다. GitHub Actions와 Preview 검증 결과를 별도로 보고한다.

## Claude 원본 녹음과 무료 기기 음성을 반드시 구분
- Google Drive의 클로드 음성강의/2_음성/01_근육학 폴더(1grQ0hGkl6Nhwj4hfhufPOjLt66zxDQux)에 근육학 제1~11권에 해당하는 원본 MP4 15개를 확인했다. 1·3·5·6권은 두 파일로 분리되어 있다.
- 무료 기기 한국어 음성은 Claude가 녹음해 둔 여성 강사 MP4를 재생한 것이 아니다.
- Cloudflare R2 바인딩·원본 MP4 객체가 연결되지 않아 서버 자동 MP4 재생은 아직 불가능하다. 1권만 수동 파일 선택형 MP4 시범을 제공하고 나머지 근육학 원본 MP4 연결은 차기 과제.
- 앱의 해부학 개별 근육 상세(205개)에 Claude 원본 녹음이 별도로 연결되어 있지 않다. 학술 강의실 근육학 원본 MP4 확보 사실과 구분할 것.
- 의장님의 2026-10-13 예정 전체 녹음 제공 후 기존 73개 MP4와 대조하여 중복/누락 확정. Runway Niki 유료 제작은 무기한 보류.

## 이후 개발 로드맵
1. 이번 v12.28의 GitHub Global QA + 모바일 87/87 강의 탐색 + 근육학 11권 native 표/이미지/본문 보존 + Cloudflare exact-SHA Preview + 설치형 PWA PASS. 실제 Android 자동 다음 강의 음성 시작은 별도 PASS가 필요하다.
2. 근육학 11권 화면·원문·TTS 억양·반복·자동 이동을 의장님 검수 기준으로 정밀 보강한다.
3. 근육총람 #1~2는 대화형 구조를 분석하고, 이학검사·연관통 및 질환외상·재활·스포츠·근거 업데이트 등의 설명형 강의를 원본 구조별 검증을 거쳐 배치마다 Native 확대한다.
4. 동적으로 질문을 생성하는 문제은행, 분류, 구술시험 등은 단순 HTML 복사로 완성이라고 판단하지 않는다. 원문 JavaScript의 문항과 정답/오답해설/채점 기능을 별도 엔진에서 동등 검증한다.
5. 녹음 MP4는 원본에 음성 타임코드가 있으면 그대로 사용하고, 없으면 무료 TTS로 보조한다. R2와 실물 Android 재생이 안정화되면 원본 녹음 연결을 확대한다.
6. 전체 87강 각각 원문 SHA·학술 그림·표·문제·출처·한국어 읽기·PWA를 검증하고 사용자 최종 승인 후에만 Production 승격을 검토한다.
