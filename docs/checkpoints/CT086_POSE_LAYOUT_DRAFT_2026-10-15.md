## 정직한 결과 판정

- **이번 단계에 실제 도해 파일 1개를 새로 제작했다.** 서비스 제공자의 출력/기존 환자사진/기존 후보 이미지를 복사하지 않고 SVG path와 gradient로 구성한 1024×1536 벡터 구도 시안이다. 같은 환자와 검사자 도형을 재사용하면서 표정/얼굴 방향을 변경한 시안으로, 움직임 교육의 구도 확인에만 사용한다.
- **실사형 의료 일러스트로 판정하지 않는다.** SVG는 실제 사람 사진처럼 보이지 않고, 검사자 위치·여성 모델의 개인 일관성·목의 3차원 자세·보상운동·해부학적 세부 구조를 의장님 또는 지정 임상의가 검수하지 않았다. `CLINICAL_POSE_PENDING`. 그림을 환자교육 정본으로 사용하거나 기존 안정 도해를 교체할 수 없다.
- **이미지 생성 서비스 사용 0회**, Runway 접속/조회/생성/원본 회수 0회, 추가 유료 도구 0회. 외부 저작권 사진·mesh·기존 승인 ct085 원본 파일을 이 시안으로 재활용하지 않았다.
- 새 벡터 시안은 모델이 코드를 작성한 프로그램 생성물에 해당한다. **인간 창작적 기여·교정·양도 또는 허락을 이 파일 하나만으로 입증했다고 주장하지 않는다.** 한국저작권위원회 CROS 작품등록 완료 아님. 관련 저작권 Gate는 그대로 유지.
- 앱의 `ct086` 검사 아래 **'신규 3장면 동작 시안 — 임상·저작권 검수 전'** 링크로 열람 가능. 명확히 `실사형 승인본이 아닙니다` 표시하고 기존 Stable-ID 교육 도해/학술설명 유지. 연결된 독립 소스 Preview 후보/승인 레지스트리는 **미변경**.
- 3가지 짧은 한국어 패널명은 `1 중립 자세 / 2 좌우 회전 / 3 제한 / 보상`. 60도·진단결론·빨간 통증 표시·강제수동회전은 의도하지 않았다. 그림 내 배경은 독자적 SVG 코드.
- 등록 QA `scripts/ct086-pose-draft-preview-qa.mjs`: 파일·텍스트/외부사진 미포함·무단승인 차단/기존 상태 보존 정적 확인. 모바일 `scripts/ct086-pending-mobile-e2e.mjs`는 링크가 실제 SVG로 열리는지 확인. 이 자동검사는 **시각적인 의학정확도를 증명하지 못한다**.
