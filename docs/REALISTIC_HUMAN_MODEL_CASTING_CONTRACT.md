# Realistic Human Medical Model Casting Contract

기준일: 2026-10-03  
상태: **LOCKED / MUST FOLLOW**  
적용범위: Physical Examination + 환자교육 운동/스트레칭 실사형 자산

## 목적

실사형 의료교육 일러스트에서 환자·검사자의 남성형/여성형 표현을 임의적·편향적으로 정하지 않고, 전체 자산에서 균형 있고 재현 가능하게 관리한다.

## 1. 기본 원칙

- 성별 표현은 진단적 의미를 암시하지 않는다.
- 특정 질환·통증·근력·순응도와 성별을 연결하는 고정관념을 사용하지 않는다.
- 같은 Stable ID 자산의 여러 패널에서는 **동일 환자·동일 검사자**를 유지한다.
- 서로 다른 검사/운동에서는 동일 인물 이미지를 재사용하지 않는다.
- 유명인·실존 환자·식별 가능한 실제 인물을 모델로 삼지 않는다.
- 연령, 체형, 피부톤, 헤어스타일 등도 교육적 가독성을 해치지 않는 범위에서 다양화한다.
- 성별과 무관한 일반 MSK 검사에서는 해부학적 노출과 손 위치가 잘 보이는 복장을 우선한다.

## 2. 기본 배정 규칙

새로 생성하는 Stable ID 자산은 숫자 ID의 마지막 두 자리 전체 값을 이용해 아래처럼 순환 배정한다.

- ID 숫자 mod 4 = 0 → 환자 여성형 / 검사자 남성형
- ID 숫자 mod 4 = 1 → 환자 남성형 / 검사자 여성형
- ID 숫자 mod 4 = 2 → 환자 여성형 / 검사자 여성형
- ID 숫자 mod 4 = 3 → 환자 남성형 / 검사자 남성형

이 규칙으로 환자와 검사자 모두 장기적으로 남성형/여성형이 1:1에 가깝게 분포하고, 네 가지 조합도 균형 있게 나온다.

예:
- ct084 → 84 mod 4 = 0 → 환자 여성형 / 검사자 남성형
- ct085 → 85 mod 4 = 1 → 환자 남성형 / 검사자 여성형

## 3. 예외

다음과 같은 경우에만 기본 배정을 바꿀 수 있다.

1. 검사 자체가 성별 특이 해부학을 직접 교육해야 하는 경우
2. 특정 연령·성별 집단을 명시적으로 다루는 근거 기반 교육자료인 경우
3. 해부학적 시인성·안전성 때문에 다른 모델 표현이 명백히 더 교육적인 경우

예외를 적용하면 registry에:
- 기본 배정
- 실제 배정
- 예외 이유
를 기록한다.

## 4. 기존 자산 처리

이미 사용자 승인을 받은 자산은 단순히 캐스팅 규칙에 맞추기 위해 다시 만들지 않는다.

- ct082 승인본: grandfathered
- ct083 현재 Candidate 2: 현재 검수 흐름을 유지
- 본 규칙은 **ct084부터 기본 강제 적용**
- 기존 승인/후보 자산을 다른 이유로 재생성할 때는 그 시점부터 본 규칙을 적용할 수 있다.

## 5. 표현 품질

- 성적 대상화 금지
- 과도한 근육 강조·패션 중심 연출 금지
- 검사 부위가 가려지는 옷 금지
- 노출은 의료교육에 필요한 최소 범위
- 환자와 검사자의 역할이 즉시 구분되어야 함
- 자세·손 위치·힘 방향·laterality가 얼굴이나 스타일보다 우선

## 6. IP / provenance

각 asset registry에 가능한 경우 다음을 기록한다.

- patient_model_presentation
- examiner_model_presentation
- casting_rule_version
- exception_reason
- gen_id
- human review / user approval
