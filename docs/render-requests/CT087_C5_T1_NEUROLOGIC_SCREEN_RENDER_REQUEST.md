English: C5–T1 motor-sensory-reflex screen

## Visual structure
4-panel vertical or 2×2:
1. 근력 — one or more anatomically correct representative C5–T1 resistance tasks.
2. 감각 — light-touch comparison of representative upper-limb dermatomal areas.
3. 반사 — anatomically plausible biceps/brachioradialis/triceps reflex assessment.
4. 분절 패턴 — concise teaching cue that motor + sensory + reflex findings are integrated.

## Clinical lock
Representative motor tasks:
- C5: shoulder abduction / elbow flexion
- C6: wrist extension
- C7: elbow extension
- C8: finger flexion
- T1: finger abduction/adduction

Representative sensory territories are teaching landmarks only because dermatomes overlap and vary.

Reflexes:
- biceps: mainly C5–6
- brachioradialis: mainly C6
- triceps: mainly C7

## Interpretation lock
- Root-level localization is pattern based.
- Do not teach one muscle/skin point/reflex as a perfect one-to-one root label.
- Distinguish radiculopathy from mononeuropathy, plexopathy, pain-inhibited weakness and myelopathy.
- Multi-level abnormality, hyperreflexia/pathologic reflexes, hand dexterity loss or gait change should trigger consideration of cord disease.
