우선순위: 의장님 최신 명시 지시. 이 지침과 충돌하는 2026-10-11 SUPER-LOCK의 **기존 35분 종료/25~30분 개발 하한/2개 제목만 사용** 세부 조항은 역사적 기록으로만 남고 실행하지 않는다. 시간 계측, 즉시 중지, 보안/배포/승인 제한은 유지된다.

## 제1원칙
- **기본 35분, 최대 50분**. 작업에 따라 개발 AI가 35분 완료 또는 최대 50분 연장 여부를 스스로 결정한다.
- **작업 시작 0분:** 실제 시각과 목표 보고.
- **15분:** 활동 점검; 가능하면 중간 상태 보고.
- **30분:** 진행·안정성·마감 가능성 점검.
- **35분:** 완료 여부와 무관하게 중간 또는 완료 보고 **필수 시도**. 미완료이고 향후 15분 내 GitHub 저장·검증까지 개선할 가치가 있으면 **35분 보고한 뒤** 연장한다.
- **45분:** 연장 활동 점검.
- **50분 절대 HARD STOP:** 미완료여도 종료한다., 미완료여도 종료·최종보고 시도. 시작시각 재설정/작업분할 위장 금지.
- 장시간 도구 호출과 채팅 플랫폼 제약으로 보고 송신이 지연되면 실제 지연을 기록하고 정상 진행으로 위장하지 않는다. 백그라운드 작업을 약속하거나 호출 없이 지속 작업했다고 주장하지 않는다.
- 사용자 **중지/중단은 USER_STOP_OVERRIDE**, 즉시 우선.

`🟢 GREEN`: 실제 개발·검증 정상 진행 / `🟡 YELLOW`: 연장·부분 실패·검증 중 / `🔴 RED`: 장애·중단·검증 불가·50분 미완료 / `🔵 BLUE`: 요구 범위 실제 저장·필수 테스트·보고 완료.
시작/35분/최종마다: 프로젝트, 신호등 상태, 지시 수령/실제 시작/현재 또는 종료/보고 시각 (모두 Asia/Seoul 실제 초 계측 또는 **확인 불가**), 실측 경과, 현재 단계, 마지막 실제 작업, HEAD 또는 미저장, 테스트 PASS/FAIL/진행, 35분 보고, 50분 연장, 다음 개발을 표시한다.

## 35분 보고 (필수)
### ① 무엇을 했나
실제 구현, 파일, HEAD.
### ② 어떻게 되었나
PASS/FAIL/PARTIAL/BLOCKED, 문제, 마지막 실측 활동.
### ③ 앞으로 무엇을 할 건가
남은 범위, 연장 이유, 50분 이내 안전 종료 판단.
**연장 결정: 50분까지 연장 / 35분 종료** 및 다음 보고 목표를 명시한다.

## 최종 보고 (35분 완료 또는 50분 HARD CUT)
프로젝트/상태/지시 수령/실제 시작/실제 종료/보고 시각/경과/시간 준수/연장 여부 표시.
**① 무엇을 했나 → ② 어떻게 되었나 → ③ 앞으로 무엇을 할 건가** 세 구역. 각 기능마다 개발자 설명, 쉬운 설명, 실제 화면에서 확인하는 방법을 포함한다. 앱 화면 변화 없으면 명확히 표시. 최종 줄은 실제 계측 **한국시간 YYYY-MM-DD HH:MM:SS KST**. 시간을 사후 추정·조작하지 않는다.
