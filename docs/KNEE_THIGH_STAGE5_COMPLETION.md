## 핵심 임상 안전 원칙
- Patellofemoral pain은 스쿼트/계단 등 기능 부하에서의 증상 재현과 감별을 함께 사용하며 단일 검사로 확정하지 않는다.
- Patellar/quadriceps tendon의 촉진·초음파 변화는 증상과 기능을 함께 해석한다.
- Valgus/varus stress는 MCL/LCL 및 더 넓은 capsuloligament injury 가능성을 평가하는 자료이며 단독으로 손상 범위를 확정하지 않는다.
- Pes anserinus는 sartorius, gracilis, semitendinosus를 구조적으로 분리한다.
- Posterior knee mass는 Baker cyst로 자동 단정하지 않으며 혈관성 병변/DVT 등 red flag를 별도 평가한다.
- Acute extensor lag/straight-leg raise failure는 extensor mechanism disruption 후보를 높이지만 통증 억제·삼출 등과 구분하고 적절한 추가 영상을 고려한다.
- Ultrasound는 실제 영상만 사용하며 생성형/가짜 B-mode를 사용하지 않는다.
- CC BY-NC-ND source figure는 변형·로컬 재배포하지 않고 canonical source reference로 연결한다.
- 환자정보/PHI, laterality 자동 추정, 시행하지 않은 검사 자동 기록을 금지한다.
