## 의장님 품질 절대 기준

- **원본 화면·정보가 나빠지거나, 설명을 요약·삭제·부실화하는 개발 금지.**
- 원문 HTML 87강은 바이트/해시 그대로 보존한다. 새 통합뷰는 복사본을 파싱하여 렌더링하는 별도 앱 엔진이다.
- 텍스트와 도표, 초음파 그림, SVG, 표, 출처/라이선스와 참고문헌을 원본보다 적게 표시하지 않는다.
- 교육용 부연 설명은 원본에 덧붙이는 별도 보강 레이어로 관리한다. 원래의 의학적 사실과 인용등급을 임의로 개변하지 않는다.
- 원본의 그림 품질이 떨어지는 재생성·확대는 금지. 원본 base64 이미지를 동일한 픽셀 데이터로 그대로 사용한다.
- 원본 MP4/인터랙션 등 제공되지 않은 기능을 가동 완료로 표시하지 않는다. 화면 전환·표·이미지와 독립된 기능은 별도 QA.
- 앱 화면/의학적 충실도 **원본 대비 회귀 여부는 의장님 Preview 확인**을 받은 뒤 다음 강으로 확장한다.
