# Claude 186 vs ChatGPT MSK Knowledge Core Audit

감사일: 2026-09-24

## 결론
Claude 패키지의 186과 기존 Knowledge Core의 183은 단순 개수 비교가 불가능하다. Claude는 승모근·삼각근·상완이두근·상완삼두근·비복근·일부 충양근/골간근을 묶어서 기록하고, Knowledge Core는 여러 head/individual muscle을 Stable ID로 더 세분화한다.

2024 Journal of Anatomy 연구는 공식 해부학 명명에 포함된 이 근육을 20/20 해부 표본에서 확인했고, MRI와 조직학으로 별도의 얇은 근육층을 뒷받침했다. 따라서 기존 'variant 후보 보류'에서 canonical muscle로 승격한다.

따라서 canonical muscle/functional-muscle records는 183 → 205로 확장한다.

## 바로 편입하지 않은 Claude 항목
- Sacrococcygeus dorsalis / ventralis: 흔적성·변이성이 크고 현대 임상 해부에서 독립 canonical skeletal muscle로 일관되게 사용되지 않아 variant structure 후보로 보류.

## 데이터 사용 원칙
- Claude 패키지의 Origin/Insertion/Function/Nerve는 참고 원자료로 사용했다.
- 정본 편입은 외부 해부학 자료로 존재·기본 구조를 재확인한 항목만 시행했다.
- Claude의 병리/촉지/초음파 빈칸이나 단정적 cutoff는 자동 이식하지 않는다.
- Stable ID는 기존 m001-m183을 절대 재사용하지 않고 신규 m184-m204를 부여했다.
