# Muscle Atlas — Realistic Human Illustration Style Contract

기준일: 2026-10-02  
상태: **LOCKED / MUST FOLLOW**  
정본 branch: `preview/development`

## 1. 공통 원칙

Muscle Atlas의 다음 두 교육영역은 최종 자산에서 **실제 사람처럼 보이는 실사형 의료교육 일러스트**를 기본 스타일로 사용한다.

1. 환자교육용 스트레칭·강화운동
2. Physical Examination / 진찰검사

막대인간, 단순 기호형 SVG, 지나치게 추상화된 인체도해는 최종품으로 사용하지 않는다. 기존 개념형 SVG는 migration/fallback 및 자동 QA용 임시자산으로만 유지할 수 있다.

## 2. 환자교육용 운동 일러스트

- 문틀 스트레칭, 경추 스트레칭 등에서 승인된 **실제 사람처럼 보이는 실사형 교육 일러스트**를 스타일 기준으로 삼는다.
- 시작자세 / 끝자세가 한눈에 구분되어야 한다.
- 동일 인물·동일 복장·동일 시점의 연속성을 유지한다.
- 움직임 방향, 지지점, 주의점, 흔한 보상동작을 필요한 범위에서 시각적으로 표시한다.
- 환자가 혼자 보고 따라 할 수 있는 수준이어야 한다.
- 모바일/PC/A4 인쇄에서 모두 가독성이 유지되어야 한다.

## 3. Physical Examination 일러스트

Physical Examination도 별도의 단순 도식 스타일을 사용하지 않고 **같은 실사형 인체 표현 계열**을 사용한다.

필수 요소:
- 실제 사람처럼 보이는 환자
- 실제 사람처럼 보이는 검사자
- 정확한 환자 시작자세
- 검사자 손 위치
- 힘/스트레스 방향
- 관절·근육·인대의 검사 방향
- 양성 소견 위치
- 필요 시 흔한 오류 / 안전 주의점

Physical Examination에서는 실사형 인물 위에 교육용 overlay를 추가한다.
- 화살표
- 손 위치 강조
- 힘 방향
- 통증/양성 위치
- 위험한 provocation 금지 표시

즉, **실사형 인체 + 검사정보 overlay**가 정본 스타일이다.

## 4. 품질 기준

- 해부학적으로 잘못된 자세 금지
- 검사자 손 위치·힘 방향 오류 금지
- 관절 가동범위 과장 금지
- 실제 임상에서 쓰기 어려운 포즈 금지
- 환자교육용과 의료진 교육용의 목적 차이는 유지하되, 인체 표현 스타일은 통일
- 특정 교과서/사진의 직접 복제·트레이싱 금지
- Stable ID별 자산 registry와 검수상태를 유지

## 5. 현재 EXAM-001과의 관계

148개 진찰검사 Stable-ID 맞춤도해 baseline은 **2026-10-02 기준 148/148 COMPLETE**다. 이 baseline은 구조·내용·힘 방향의 정본이며, EXAM-REAL-001 실사형 승격에서 각 후보의 임상 정확도 기준으로 계속 보존한다.

그 후 최종 시각자산은 순차적으로:
`개념형/구조도해 → 실사형 Physical Examination 일러스트`
로 승격한다.

현재 baseline 맞춤도해를 “최종 실사형 완성품”으로 오기하지 않는다.

## 6. 완료 Gate

Physical Examination 최종 승격 시:
- 실사형 환자/검사자 표현
- 손 위치·힘 방향 정확성
- 3단계 시작/시행/양성 판단
- 모바일/PC visual QA
- 사용자 Preview 확인
를 모두 통과해야 한다.

환자교육 운동 최종 승격 시:
- 실사형 인체
- 자세 정확성
- 시작/끝 동작 연속성
- 텍스트 안전성
- 모바일/PC/A4 QA
- 사용자 Preview 확인
을 모두 통과해야 한다.
