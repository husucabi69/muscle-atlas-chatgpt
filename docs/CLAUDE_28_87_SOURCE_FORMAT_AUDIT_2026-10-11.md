## 각 배치 공통 수락 기준
1. 원본 절대 무변경: file byte length + SHA-256/manifest 일치.
2. 신규 앱 화면에서 원문 텍스트, 표, figure, 이미지, 읽기 구간 수와 장 목차 일치. 원본 내 애니메이션·정답/문항·운동 동작을 작동하지 않는 장식 텍스트로 교체 금지.
3. Android 반응형 화면·읽기/정지/일시정지/배속/반복·원본 비교/뒤로가기·PWA 실행시 자동업데이트 브라우저 회귀 확인. **모의 음성 PASS와 실물 Android PASS를 엄격 구분**.
4. 서버 MP4 자동 연결이 실재하지 않으면 `R2_BLOCKED`를 유지, 무료 기기 음성이라고 명확히 안내. mp4가 있는 원본에 기기 TTS만 이식하고 전체 녹음이 연결됐다고 과장 금지.
5. 앱 `preview/development`에서 Global QA 3종과 Cloudflare stable Preview 확인, Production main 사용자 승인 전 동결.
