## 검증 기준
- 인앱 원본 19장/49표/18그림/671 표시자 **그대로**.
- 추가 보강 5개, 합계 676개 읽기 구간. 목소리 선택기가 없다면 기본 한국어 음성 시도.
- 원본 MP4 파일을 임의로 다운로드한 것처럼 보이지 않고, 오디오 기능은 자체 TTS로 명확히 표시.
- Global QA, browser E2E, exact Preview Gate, 설치형 PWA 회귀 검증; **실제 Android 음질은 의장님 직접 검수 대기**.
- 실제 Android에서 목소리가 듣기에 부자연스러우면 음색 조정/대체 무료 모델을 검토하되 Niki 유료 재개는 별도 승인 필요.

## 재생 파이프라인 QA 보강

- 기존 87강 브라우저 E2E에서 근육학 1권 통합 강의에 진입한 후, 표준 Web Speech API의 **시험용 가짜 음성 엔진**을 통한 `speak()` 호출을 관찰한다.
- 실제 원문 발화 길이 ≤160자, 한국어 `ko-KR`, 재생 시작 및 정지 상태 변화를 자동 검증한다.
- 이 시험은 텍스트가 음성 엔진에 전달되는지 확인하는 **시뮬레이션 테스트**다. 실제 Samsung/Google 기기의 발음·음색 검수는 별도.
- 학습 진행위치, 목소리 이름, 배속은 해당 기기의 `localStorage`에만 저장한다. 병원 환자정보를 전송하거나 저장하지 않는다.
