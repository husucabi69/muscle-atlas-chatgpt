# 근육학 1권 한국어 음성 v12.25: 무료 기기 음성 읽기 (2026-10-10)

## 범위 및 비용
- **유료 Runway Niki 계획은 보류 유지**, 구매/크레딧 사용/재생성 없음.
- 기존 Claude 선희 MP4 1·2부는 파일 참조 및 동기화 정보가 HTML에 있으나 Google Drive에는 실제 MP4가 검색되지 않았고, Cloudflare Preview R2는 \`Audio storage not connected\` 상태. **원본 녹음파일 재생이 가능하다고 주장 금지**.
- 실제 청취 기능은 브라우저 표준 \`speechSynthesis\`로 만든 **무료 한국어 기기 음성 읽기**. OS TTS 음성 품질/음색/설치 여부는 휴대전화에 따라 다름. 전문 여성 강사 Niki 음성과 동일하지 않음.

## 실제 화면 사용
Preview → 학술 강의실 → 근육학 → **근육학 01권 어깨·견갑대** → 우리 앱 통합 강의
- 🎧 **강의 듣기 · 무료 한국어 음성**.
- ▶ 읽기, ⏸ 일시정지/계속, ⏹ 정지, ⏮ 이전 문단, 다음 문단 ⏭, 한국어 목소리 선택, 0.85~1.3배속.
- **선택한 장부터 듣기** 버튼: 상단 '학습할 근육 또는 장 선택'에서 장을 고르면 거기서부터 읽기.
- 원문 671개 \`data-i\` 학습 구간 + 5개 설명형 보강 해설을 문서 순서대로 읽음. 160자 이하로 발화를 나눠 일부 모바일 브라우저 TTS의 긴 발화 끊김 문제 완화.
- 화면 원문은 보존하고 재생하는 문단을 강조, 해당 문단 터치로 거기서부터 읽기.
- 다른 강의/원본 비교/뒤로가기/앱 전환 시 음성 종료; 시스템 설정·브라우저 정책으로 일시정지/음성 목록 미지원될 수 있음.

## 검증 기준
- 인앱 원본 19장/49표/18그림/671 표시자 **그대로**.
- 추가 보강 5개, 합계 676개 읽기 구간. 목소리 선택기가 없다면 기본 한국어 음성 시도.
- 원본 MP4 파일을 임의로 다운로드한 것처럼 보이지 않고, 오디오 기능은 자체 TTS로 명확히 표시.
- Global QA, browser E2E, exact Preview Gate, 설치형 PWA 회귀 검증; **실제 Android 음질은 의장님 직접 검수 대기**.
- 실제 Android에서 목소리가 듣기에 부자연스러우면 음색 조정/대체 무료 모델을 검토하되 Niki 유료 재개는 별도 승인 필요.
